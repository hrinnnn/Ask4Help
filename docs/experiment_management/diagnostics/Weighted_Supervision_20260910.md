# 权值型监督分数：长度与偏移分别计价

本轮只使用用户指定的π0.5三任务12组；无Stage2旧实验、无模型TNS旧拟合。全部为已有数据上的探索，不是新训练结果。

用户要求：正常演示较长与偏离后恢复应有不同代价；输出权值而非相容点比例。

## 本轮已计算的候选

\[ S(\mathcal D)=P-\alpha L-\beta R. \]

P为全部OOD专家动作数除以新增ID+OOD总专家动作N。L为每条OOD轨迹超过其匹配完整成功参考长度的额外动作数，汇总后除以N。R为所有OOD点超出原校准半径的偏移平方总和，除以N：

\[ R=\frac{1}{N}\sum_{i\in\mathrm{OOD}}\sum_t\left[\max\!\left(\frac{d_{it}}{\tau_i}-1,0\right)\right]^2. \]

这里ID没有正向贡献，仍保留在预算分母。S可以为负，因此是按专家预算标准化的净效用分数，不是相容概率。它也不能直接当作允许负值的训练loss采样权重。

长度只扣超过完整成功参考的部分，避免把正常BC轨迹长本身当作错误；这同时意味着短后缀里的冗余可能无法被识别。参考来自BC示范，BC天然更接近该分布；不能将参考接近度本身等同于教学价值。

## 当前判断

1. 加强偏移惩罚能修正SC中BC被低估的问题：长度0.25、偏移1时，Gate>BC>Recovery>Diff，ρ=.8；仍未排对Recovery/Diff。
2. Plane的BC轨迹很接近BC参考，但真实SR为0；统一加重偏移会高估它，因此该候选尚未解决三任务共同排序。
3. YCB的BC48/Recovery49/PCA52差异较小，不能为了精确追这几个点而单独调系数。
4. alpha在0/.25/1范围未改变排名，说明这批数据按当前定义的超额长度占比很小；不是长度代价已经被充分验证。
5. 几何偏离不等于真正Recovery，平方惩罚还可能被少数极端点主导；需要逐片段辨别合法不同路径、直接目标行为、冗余与纠错，再决定惩罚。
6. 本轮候选α=.25、β=1的三任务均值约.267，低于上轮全轨迹×6的.4，但SC更好、YCB更好、Plane更差。不能说整体已经取代全轨迹×6。
