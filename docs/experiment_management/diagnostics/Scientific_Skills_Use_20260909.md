# Scientific Skills 使用记录

本次用 Experimental Design、Scientific Critical Thinking 和 Hypothesis Generation 辅助检查配对设计、区分开发与确认结果，以及在原规则无增益后列出测量盲点和竞争解释。它们不提供实验结果，也不替代作者核验。原版结果、候选修订和独立新seed结果分别保留。

工具文献：Timothy Kassis, Vinayak Agarwal, Yuhuan He, Darshil Patel, Aubrey M. Brueckner (2026). *Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents*. [arXiv:2609.00065](https://arxiv.org/abs/2609.00065), DOI [10.48550/arXiv.2609.00065](https://doi.org/10.48550/arXiv.2609.00065)。2026-09-09核对官方记录，当前修订日期2026-09-02；这里只作工具使用归属，不加入论文的方法有效性证据。
